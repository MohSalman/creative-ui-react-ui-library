# Border Radius

Corner radius tokens for consistent rounding.

## Scale

| Token | Value | Use case |
|-------|-------|----------|
| `xs` | 4px | Badges, tags |
| `sm` | 6px | Buttons, inputs |
| `md` | 8px | Cards, modals |
| `lg` | 12px | Panels |
| `xl` | 16px | Large surfaces |
| `xxl` | 24px | Hero sections |

## Usage

```css
border-radius: var(--radius-sm);
border-radius: var(--radius-md);
```

## Guidelines

- Use `sm` for form controls and buttons.
- Use `md` for cards and modals.
- Use `xl` or `xxl` for prominent containers.
