# useBreakpoint

Hook to react to viewport breakpoint changes.

## Status

**Coming soon.** This hook will:

- Return current breakpoint (xs, sm, md, lg, xl)
- Update on window resize
- Support custom breakpoint values

## Planned API

```tsx
const breakpoint = useBreakpoint();
// 'xs' | 'sm' | 'md' | 'lg' | 'xl'

const isMobile = useBreakpoint() === 'xs' || useBreakpoint() === 'sm';
```
