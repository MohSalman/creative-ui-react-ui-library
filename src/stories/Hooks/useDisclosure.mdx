# useDisclosure

Hook to manage open/close state for modals, drawers, dropdowns, and similar UI.

## Status

**Coming soon.** This hook will return:

- `isOpen` – current state
- `onOpen` – open
- `onClose` – close
- `onToggle` – flip state

## Planned API

```tsx
const { isOpen, onOpen, onClose, onToggle } = useDisclosure(false);
```
