# Accessibility Utilities

Helpers for keyboard navigation, focus management, and ARIA.

## Status

**Coming soon.** Planned utilities:

- `focusTrap` – trap focus within a modal/drawer
- `focusFirst` – focus first focusable in a container
- `isFocusable` – check if element can receive focus
- ARIA helpers for live regions, announcements

## Guidelines

- Use semantic HTML
- Provide `aria-label` or visible labels
- Support keyboard navigation
- Ensure sufficient color contrast
