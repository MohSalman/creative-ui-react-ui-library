# Popover

A popover displays floating content anchored to a trigger element.

## Status

**Coming soon.** This component will support:

- Positioning (top, bottom, left, right)
- Portal rendering
- Click outside to close
- Arrow/pointer

## Usage (Planned)

```tsx
<Popover trigger={<Button>Open</Button>}>
  <PopoverContent>Content here</PopoverContent>
</Popover>
```
